# Health Data Science Lab

Personal laboratory dedicated to Health Data Science, Digital Health,
eLMIS, Monitoring & Evaluation, Data Quality and reproducible analytics.

## 🎯 Objectives

This laboratory is designed to:

- develop practical Data Science skills applied to health;
- strengthen data quality and Monitoring & Evaluation practices;
- explore Digital Health and eLMIS use cases;
- develop reproducible data analysis workflows;
- document methods, indicators and analytical approaches;
- build a professional portfolio in Health Data Science.

## 🏥 Main Areas

### 1. Health Data Science
- Data cleaning
- Data validation
- Exploratory Data Analysis
- Data visualization
- Statistical analysis
- Reproducible workflows

### 2. Digital Health
- eLMIS
- DHIS2
- Health information systems
- Digital transformation
- Health data interoperability

### 3. Monitoring & Evaluation
- Indicators
- Data Quality Assessment
- Performance monitoring
- Data quality scorecards
- Reporting

### 4. Supply Chain & eLMIS
- Stock data
- Stock on Hand (SOH)
- On Shelf Availability (OSA)
- Frequency of Use
- Data quality
- Logistics indicators

## 🔬 Projects

Projects will use synthetic, anonymized or publicly available datasets.

## 🔐 Data Protection

No confidential, personally identifiable or restricted operational data
should be uploaded to this public repository.

Demonstration datasets will be synthetic, anonymized or publicly available.
